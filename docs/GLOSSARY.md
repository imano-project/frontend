# GLOSSARY.md

IMANO のドメイン用語と、コード上の名前の対応表です。
AI エージェントは、型・変数・関数に名前を付けるとき、このファイルの「コード上の名前」を使ってください。

> 新しい用語を作ったとき、または名前を変えたときは、同じコミットでこのファイルも更新する。
> 同じ概念に別の名前を使わない（例: 同じ「ユーザー」に User / Member / Account を混ぜない）。

最終更新: 2026-11-10

## 用語

| 用語 | コード上の名前 | 意味 | 使わない名前 |
|---|---|---|---|
| 位置情報 | `LocationInfo` | 端末の現在地（緯度・経度）と、それを取得した時刻 | |
| 移動状態 | `MovementState` | 端末を持つ人が止まっている・歩いている・走っている・自転車・車のどれか。判定できないときは不明（`unknown`） | |
| 設定 | `Setting`（画面は `SettingView`、タブは `TabItem.settings`） | 設定画面（タブの1つ）。中身は未定 | |
| タブ | `TabItem` | 画面下のタブバーの項目。ホーム・ルール・設定の 3 つ | |
| 天気情報 | `WeatherInfo` | 現在の気温と天気、今日の最高・最低気温、降水確率、更新時刻 | |
| ホーム | `Home`（画面は `HomeView`） | ホーム画面（タブの1つ）。日付・時刻、位置情報、移動状態、天気を表示する | |
| ルール | `Rule`（画面は `RuleView`） | ルール画面（タブの1つ）。何を指すかは TODO | |

> TODO: 「設定」は画面が `Setting`、タブが `settings` で単数・複数がそろっていない。どちらに合わせるか決める。

## 書き方のルール

- 1用語1行。五十音順に並べる
- 「コード上の名前」は型名の形（UpperCamelCase）で書く。変数ではその lowerCamelCase を使う
- 「意味」は1文で、アプリの中で何を指すかを書く
- 「使わない名前」には、紛らわしくて使わないと決めた名前を書く
- backend と名前が違う場合は、「意味」に backend 側の名前も書く（API の中身は [API.md](API.md)）
- 更新したら「最終更新」の日付も変える
