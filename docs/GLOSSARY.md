# GLOSSARY.md

IMANO のドメイン用語と、コード上の名前の対応表です。
AI エージェントは、型・変数・関数に名前を付けるとき、このファイルの「コード上の名前」を使ってください。

> 新しい用語を作ったとき、または名前を変えたときは、同じコミットでこのファイルも更新する。
> 同じ概念に別の名前を使わない（例: 同じ「ユーザー」に User / Member / Account を混ぜない）。

最終更新: 2026-10-20

## 書き方のルール

- 1用語1行。五十音順に並べる
- 「コード上の名前」は型名の形（UpperCamelCase）で書く。変数ではその lowerCamelCase を使う
- 「意味」は1文で、アプリの中で何を指すかを書く
- 「使わない名前」には、紛らわしくて使わないと決めた名前を書く
- backend と名前が違う場合は、「意味」に backend 側の名前も書く（API の中身は [API.md](API.md)）
- 更新したら「最終更新」の日付も変える
