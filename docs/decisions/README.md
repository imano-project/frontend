# decisions/

決めたことと、その理由の記録（ADR: Architecture Decision Record）です。
AI エージェントは、ここに記録された決定を勝手に変えないでください。変えたほうがよいと思ったら、提案して確認してください。

## いつ書くか

- 構成、ライブラリ、ツール、命名などの方針を決めたとき
- 以前の決定を変えたとき（古いファイルは消さず、状態を「置き換え」にして新しいファイルへのリンクを書く）

## ファイル名

`0001-短い英語の名前.md` のように、4桁の通し番号から始める。番号は使い回さない。

## 一覧

| 番号 | タイトル | 状態 |
|---|---|---|
| [0001](0001-record-decisions.md) | 決めたことを ADR で記録する | 採用 |

## テンプレート

```markdown
# 0000. タイトル

- 状態: 提案 / 採用 / 置き換え（→ 0000）/ 取りやめ
- 日付: YYYY-MM-DD

## 背景
何に困っていたか、何を決める必要があったか。

## 決定
何を決めたか。

## 理由
なぜそうしたか。比べたほかの案と、選ばなかった理由。

## 影響
これによって何が変わるか。気をつけること。
```

新しく書いたら、上の「一覧」にも1行足す。
